演習ノートブックの形式は2部で異なります。

- **q1–q7**: 空欄（`# ここにあなたのコードを書いてください`）を生徒自身が埋めて完成させる形式。
- **q8–q17**: **理解重視フォーマット**。これからの時代は「コードを書くのは AI、ハイパーパラメータや特徴量の設計を人間が担う」という考えに基づき、コーディングそのものではなく **AI（機械学習）の中身の理解** を測ります。

### 理解重視フォーマット（q8–q17）

コードは **ボイラープレート（読み込み・前処理の枠組み・描画など）を完成形で提供** します（AI に書かせてもよい）。ただし q1–q7 のように全部を書かせるのではなく、**各問の「核心となる最低限の数行」だけを `# ★あなたが書く★` として空欄**にしてあり、ここは生徒が自分で書きます。これにより「要となる処理は理解して書ける」ことも確認します。生徒は次の4つの仕組みで「理解していること」を提出物で示します。各問の見出しにタグが付きます。

| タグ | 意味 | 生徒がすること |
|------|------|----------------|
| **【骨格】** | 動く骨格は与えられている | 設計上の決定点（数値・選択肢・特徴量）を変更し、**核心の最低限コーディング**（`# ★あなたが書く★`）を埋める |
| **【選択】** | 適切な手法を選ぶ問題 | 「ここで適切な処理をしないと精度が上がらない」場面で **5〜6個の候補（A〜F）** から選び、**理由**を解答欄に書く（不適切な候補も混在） |
| **【実験】** | 試行錯誤の記録 | ハイパーパラメータや特徴量を **2軸以上で最低5通り** 変え、結果を **実験ログ表** に記録し、**考察**する（q8 は `settings` ループで決定木と KNN × 補完 × スケーラを CV で比較、q14–q16 は `EXPERIMENTS` リストが標準） |
| **【探索】** | 最適設定を自分で探す（**q9–q17**） | **仮説 → 試行 → 記録 → 次の仮説** を **15回前後以上**繰り返し、最適な設定を自分で見つける。試行は `Lab`（記録帳）に自動で溜まる。探索に使ってよいのは検証スコア（CV など）だけで、**テストは最後に1回だけ**（`lab.final_test`。2回目はエラー） |
| **【指示書】** | 知識を LLM に渡す（**q9・q13・q17** の最終問） | 実験で得た知識（目的・探索範囲・罠・止めどき・検証方法）を LLM に渡せる**指示書**に書き起こし、実際に LLM に渡して、出力を**自分のログで ○× 採点**する |
| **【説明】** | 理解の証跡 | 与えられたコードの各行に `# 説明:` で意味を自分の言葉で書く（このタイプはコードは完成形のまま） |

#### 試行錯誤型フォーマット（q9–q17）

q9–q17 では「正解のパラメータ」を教えず、生徒が**何度も試して最適設定を探す**構成です。全回で次の共通の仕組みを使います。

| 仕組み | 内容 |
|---|---|
| `Lab`（記録帳） | 最初のコードセルに実装済み。`run_trial(...)` を何度実行しても、試行番号・設定・スコア・仮説・補助指標が1行ずつ自動で溜まる。`lab.df()` で表、`lab.plot()` でグラフ、`lab.report()` で探索の自己診断（回数・範囲・端に張り付いていないか・仮説を書いたか）、`lab.save()` で CSV 保存。同じ設定は重複記録されない |
| 検証とテストの分離 | 探索の物差しは検証スコア（訓練データ内の CV、または取り分けた検証用データ）。テスト（または holdout）は `lab.final_test()` で**1回だけ**評価（2回目はエラー） |
| 実験前の予測 | 実験を始める前に予測と理由を書く（書き直し禁止）。予測と結果のズレが「得た知識」の証拠になる |
| 探索の記述 | 探索の進め方（試行番号 `#n` を引用）、仮説が外れた試行から学んだこと、僅差の設定が `cv_std` の範囲内か |
| 指示書問題 | q9・q13・q17 の最終問で、得た知識を LLM への指示書（6項目のひな形）にまとめ、LLM の出力を自分のログで採点する。負担を考えて毎回ではなく3回に絞っている |

| 回 | 探索する対象 | 探索の物差し | 最後の1回 |
|---|---|---|---|
| q9 | Ridge/Lasso（model×alpha×degree）、ロジスティック回帰（penalty×C×degree×特徴量グループ） | CV R² / CV 正解率 | テスト |
| q10 | GradientBoosting（n_estimators×max_depth×learning_rate×subsample）。データはラベル誤り 8% の人工データ（乳がんデータでは差が出ないため） | CV 正解率 | テスト |
| q11 | クラスタリング（algo×k×scale×pca_dim） | シルエットスコア | 正解ラベルとの一致度 ARI |
| q12 | 不均衡データ（pos_weight×threshold×C。「Recall≥0.80 で Precision 最大」）。データは陽性 5.5%・`class_sep=1.0`（何もしない設定は Precision 0.86 / Recall 0.54、制約を満たす最良は Precision 0.4〜0.5 程度） | 制約つき目的関数（OOF 予測） | テスト |
| q13 | 決定木（max_depth×min_samples_leaf×ccp_alpha×criterion）＋GridSearchCV との比較。データはラベルの 15% を反転させた乳がんデータ | CV 正解率 | テスト |
| q14 | MNIST の前処理×学習設定（key×lr×epochs×batch_size×seed） | 検証用 2000 枚の正解率 | テスト |
| q15 | MLP（lr×hidden×epochs×depth×seed） | 検証用 2000 枚の正解率 | テスト |
| q16 | 3モデル（model×lr×epochs×hidden1×batch_size） | 検証用 2000 枚の正解率 | テスト |
| q17 | 現場入力に合わせた前処理（invert×thin_kernel×threshold×center）。現場画像は1枚ごとにずれ・線の太さが違う | 開発用 1000 枚の正解率 | holdout 1000 枚 |

> 従来の【実験】タグ（固定の `EXPERIMENTS` リスト・表への転記）は q8 と、q9–q17 の一部の補助的な実験に残っています。

> **q1–q7 との違い**: q1–q7 は空欄をすべて埋めて完成させる形式ですが、q8–q17 は「ボイラープレートは提供・核心の数行だけ書く」点が異なります。空欄は `# ★あなたが書く★` とヒント（`ヒント:`）、未記入箇所は `TODO()` で示します（`TODO()` のまま実行すると「空欄が残っています」というエラーで止まる。Jupyter では `___` が組み込み変数で空文字になり、空欄のままでもエラーにならないことがあるため `TODO()` にしている）。

各問の最後に **✍️ 解答用コードセル**（`# === ✍️ 問題N 解答（採点対象）===`）があり、選んだ選択肢・理由・実験結果・考察を **項目ごと（例 `(2-a)` `(2-b)`…）** に記入します。これが主な採点対象です。見本は [`q8.ipynb`](q8.ipynb)（機械学習系）と [`q16.ipynb`](q16.ipynb)（深層学習系）です。

#### 解答用コードセルの命名（q8–q17 共通）

| 用途 | 変数名の例 | 備考 |
|------|------------|------|
| 選択肢（A〜F） | `design1_choice`, `design2_1_choice`, `answer_4_a` | 問題文の **(A)〜(F)** と解答セルのコメントを必ず照合 |
| 理由・考察（短文） | `design1_reason`, `answer_3_b`, `reflection2` | 複数行は `""""""` |
| 実験ログ | `experiment_log`, `experiment_log_axis1` | 実行セルが出す `experiment_log_run` を転記してもよい |
| 観察表 | `observation_1_a` | `pd.DataFrame` または文字列 |
| 説明問題のコード内 | `# 説明:` コメント | 別セルの `answer_N_a` と併用する回あり |

採点時は **markdown の選択肢定義を正**とし、解答セル先頭の `# (A) ...` コメントが一致していることを確認してください。

## データセット

演習で使用する CSV は [`data/`](data/) に配置しています。  
ノートブックからは GitHub の raw URL 経由で読み込みます。

```
data/
├── covid/newly_confirmed_cases_daily.csv   # q2, q4
├── student/student-mat.csv                 # q3, q4, q7, q9
├── student/student-por.csv                 # q3
├── titanic/titanic.csv                     # q5, q8, q10
├── titanic/train.csv, test.csv             # Kaggle 形式
└── sklearn/                                # 参考用 CSV（iris, wine など）
    ├── breast_cancer.csv
    ├── digits.csv
    ├── iris.csv
    └── wine.csv
```

データ読み込みのベース URL:

```
https://raw.githubusercontent.com/ShotaYmzk/AI-kadai/main/data
```

使用例:

```python
import pandas as pd

df_cvd = pd.read_csv(
    "https://raw.githubusercontent.com/ShotaYmzk/AI-kadai/main/data/covid/newly_confirmed_cases_daily.csv",
    index_col=None,
)
```

```python

```

q17 の手書き推論 UI は **Google Colab** 上での実行を推奨します。Colab では q14〜q16 を順に実行後，q17 を開いてください。ローカル Jupyter では q17 の問題1（モデル読み込み）と問題3（考察）のみ実施可能です。
