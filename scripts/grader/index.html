AI 設定

選択・モデル・rpm と Gemini キーはこのPCの scripts/grader/.settings.json に保存（権限600・git管理外）。環境変数 GEMINI_API_KEY でも可。採点内容は選択したAIへ送信されます。

採点 UI の使い方

全体の流れ： Classroom から提出ノートをダウンロード → 提出物/第N回/ に置く（または左の追加欄へドロップ）→ 回を選ぶ → 提出を開いて手動または AI 採点。

起動

python3 scripts/grader/server.py をリポジトリ直下で実行し、http://127.0.0.1:8765 を開きます。別ポートは --port 8799、自動で開くには --open。Python 3 だけで動き、pip の追加インストールは不要です。

Gemini確認中
  • Claude Code： 公式手順でインストールし、ターミナルで claude を一度起動してログインします。
  • Codex： 公式手順（例 npm i -g @openai/codex）でインストールし、codex login で ChatGPT アカウントまたは API キーを使ってログインします。
  • Gemini： Google AI Studio で API キーを作り「AI設定」に貼るか、GEMINI_API_KEY を設定します。無料枠には毎分・毎日の上限があり、rpm は呼び出し間隔を抑える値です（例 12 = 毎分最大12回）。

保存と個人情報

結果は 提出物/第N回/_採点/grades.json に自動保存されます。提出ノートと採点結果は個人情報を含むため、Git に追加・commit・push しないでください。

よくあるエラー

  • モデル不可： アカウントで使えないモデルです。Codex は「Codex の既定」に戻してください。~/.codex/config.toml の model が原因になる場合もあります。
  • API 上限： Gemini の rpm を下げるか、毎日枠の回復を待ちます。
  • タイムアウト： 一時的な混雑や大きな答案が原因です。再試行するか軽いモデルを選びます。
  • ノートが読めない： JSON として壊れていない .ipynb か、正しい回に置いたか確認します。
  • 解答例なし： q1〜q7 などは問題文・答案・実行結果だけで AI が判断します。必ず人が結果を確認してください。
