# 採点 Web UI

q1〜q17 の Jupyter Notebook 提出を、ブラウザで確認・採点するローカルツールです。Python 3 の標準ライブラリだけで動き、pip による追加インストールは不要です。

## 基本の流れ

1. Classroom から学生の `.ipynb` をダウンロードします。
2. `提出物/第N回/` に置きます。UI へのドラッグ＆ドロップでも取り込めます。
3. リポジトリ直下でサーバを起動します。
4. 回と提出を選び、手動または AI で採点します。AI の結果は必ず人が確認してください。

```sh
python3 scripts/grader/server.py
```

`http://127.0.0.1:8765` を開いてください。別のポートは `--port 8799`、既定ブラウザを自動で開く場合は `--open` を使います。オプション一覧は `python3 scripts/grader/server.py --help` で確認できます。

## AI プロバイダの準備

### Claude Code

Claude Code を公式の手順でインストールし、ターミナルで `claude` を一度起動してログインします。採点時はツールを無効にし、空の一時ディレクトリで実行します。

### OpenAI Codex

Codex CLI を公式の手順でインストールします。例:

```sh
npm i -g @openai/codex
codex login
```

`codex login` で ChatGPT アカウントまたは API キーを使ってログインします。モデルが利用できない場合は、UI で「Codex の既定」を選びます。`~/.codex/config.toml` の `model` がアカウントで使えないモデルだと、モデル未指定でも失敗する場合があります。

採点時は `codex exec` を読み取り専用サンドボックス、空の一時 cwd、セッション非保存で実行します。

### Gemini API

Google AI Studio で API キーを作り、UI の「AI設定」に貼るか、環境変数 `GEMINI_API_KEY` に設定します。無料枠には毎分・毎日の上限があります。`rpm` は「1分間に最大何回呼ぶか」の上限で、例えば 12 なら呼び出し間隔を約5秒以上にします。

UI の「使い方」に、各プロバイダの現在状態と「接続テスト」があります。テストは短いプロンプトを1回だけ送信します。

## 解答例の有無

`解答/qN.ipynb` がある回は模範解答と比較します。無い回は「解答例なし」モードとなり、問題文・学生の答案・実行結果だけで AI が論理の正しさや理解を評価します。判定の不確実性が高いため、特に人による確認が必要です。後から解答ノートを置けば、次の読み込みから自動で通常モードになります。

## 保存先と取り扱い

採点結果は `提出物/第N回/_採点/grades.json` に自動保存されます。提出ノートと採点結果は個人情報を含むため、Git に追加・commit・push しないでください。`.settings.json` も gitignore 対象で、保存時のファイル権限は 600 です。

## よくあるエラー

- **model is not supported / モデル不可**: 利用権限のあるモデルへ変えます。Codex はまず「Codex の既定」を試します。
- **HTTP 429 / API 上限**: rpm を下げるか、毎日枠の回復を待ちます。
- **タイムアウト**: 混雑が収まってから再試行するか、軽いモデルを選びます。
- **ipynb を読めない**: 拡張子だけを変えたファイルでないか、JSON が壊れていないか、正しい回のフォルダかを確認します。
- **未記入と表示される**: 解答セルや見出しの削除、テンプレートのまま、想定外の並び替えが原因の可能性があります。
